# Pixelify Sans — tipografía de Cheese

Se incluyen **las cuatro variantes TTF sin modificaciones** suministradas por el equipo y la licencia completa `OFL.txt`.

| Variante | Uso en Godot |
| --- | --- |
| Regular | Descripciones, mensajes, ayudas, historial |
| Medium | Etiquetas, selectores, dropdowns, estados, coordenadas |
| SemiBold | Acciones secundarias, títulos de secciones, nombres de modos |
| Bold | Acciones principales de inicio, títulos grandes y modales |

`PixelUiSkin.FontFor(UiFontWeight)` carga y almacena las variantes para reutilizarlas. El logo CHEESSE es un PNG y no se modifica.
